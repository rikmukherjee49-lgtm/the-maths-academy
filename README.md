# The Mathematics Academy — IIT JEE Edition

A beginner-friendly React + Vite website for IIT-JEE Mathematics (Classes 11 and 12), covering both JEE Main and JEE Advanced.

**Created by Sarbasis Mukherjee**

## Run Locally

1. Open this folder in VS Code.
2. Open Terminal → New Terminal.
3. Run `npm.cmd install`.
4. Run `npm.cmd run dev`.
5. Open the local URL shown in the terminal (usually http://localhost:5173/).

## Project Files

- `src/App.jsx` — Homepage content, chapter lists and interactive UI.
- `src/style.css` — Website design and responsive layout.
- `src/main.jsx` — React entry point.
- `src/SetsChapter.jsx` — Sets chapter lessons and practice sections.
