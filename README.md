# The Maths Academy — JEE Edition

A beginner-friendly React + Vite starter website for IIT-JEE Mathematics (Classes 11 and 12), covering both JEE Main and JEE Advanced.

## Run locally
1. Open this folder in VS Code.
2. Open Terminal → New Terminal.
3. Run `npm.cmd install`
4. Run `npm.cmd run dev`
5. Open the local URL shown in the terminal (usually http://localhost:5173/).

## Files
- `src/App.jsx` — homepage content, chapter lists and interactive UI
- `src/style.css` — website design and responsive layout
- `src/main.jsx` — React entry point

This is a front-end starter. Chapter lesson pages, question banks, tests, accounts and saved progress will be added in later steps.
